How a ViT sees a picture

One tiny example, step by step: a 6×6 picture of the letter L, cut into four patches that "talk" to each other. The Vision Transformer in the relearning experiment does exactly this, just bigger. The companion page How a CNN sees a picture walks through the ResNet-18 way with the same letter.

A CNN slides a small filter over every spot. A ViT instead cuts the picture into a few squares, called patches, and treats each one as a word in a sentence. Here: 4 patches of 3×3 pixels. In the experiment: 64 patches of 4×4 pixels.

Step 3 · Tokens

Each patch becomes a short list of numbers

Tokenvertical strokehorizontal strokeink

Each patch's pixels are multiplied by a learned table of weights, giving a short list of numbers: the patch's token. Here we picked 3 easy-to-read numbers by hand. In the experiment, each 4×4×3 patch (48 pixel values) becomes 384 numbers.

Notice what is missing: patch 1 and patch 3 both say "vertical stroke", but nothing yet says where they were.

Step 4 · Position and the class token

Add where each patch was, and one extra "summary" slot

classpatch 1 · top leftpatch 2 · top rightpatch 3 · bottom leftpatch 4 · bottom right

A learned position tag is added to every token, so the network knows which patch came from where. Then one extra token is put in front: the class token. It starts as the same learned list for every picture and contains nothing about this picture. Its job is to collect a summary of the whole picture as it passes through the network.

Step 5 · Attention

Every token looks at every other token

The class token asks…How relevant?weight
patch 10.25
patch 20.05
patch 30.45
patch 40.25

Each token scores how relevant every other token is to it (the scores add up to 1), then takes the weighted mix of their numbers. The class token gives most weight to patch 3, the corner, and almost none to the empty patch 2:

vertical = 0.25·1 + 0.05·0 + 0.45·1 + 0.25·0 = 0.70
horizontal = 0.25·0 + 0.05·0 + 0.45·1 + 0.25·1 = 0.70

Now the class token "knows" the picture has both a vertical and a horizontal stroke, meeting at a corner. The weights are not fixed: they are computed from the tokens themselves, so each picture gets its own pattern. The patch tokens do the same, so patch 1 can learn that a horizontal stroke sits below it.

The key difference from a CNN: a CNN filter only sees a 3×3 neighbourhood, and the network has to stack many layers before far-apart parts of the picture meet. In a ViT, every patch can look at every other patch from the very first layer. The price: a ViT has no built-in idea that nearby pixels belong together, so it must learn that from data. That is why it needs more data, or strong augmentation, to do well on small datasets.
Step 6 · Blocks

Repeat: attention, then a small network for each token

One transformer block is: attention (step 5), then a small two-layer network applied to each token on its own. Each part is wrapped with LayerNorm, which rescales each token's numbers, and a skip connection that adds the input back. The experiment's ViT stacks 6 blocks, and each block runs 6 attention patterns side by side (6 "heads"), each free to look for something different.

Why LayerNorm matters for the experiment: a ResNet uses BatchNorm, which keeps running averages of all the training data it has seen. When it trains on house numbers (SVHN), those averages move to SVHN. LayerNorm keeps no such averages: it only uses the current image. This may be why the ViT's old CIFAR-10 head looked less forgotten after SVHN than ResNet-18's (29% vs 19%).
Step 7 · The head decides

After the last block, the class token's numbers are the picture's features: 384 numbers in the experiment. The head is the same kind of small linear layer as in the ResNet: it scores each answer and the highest wins. Everything before it is the backbone, which is why the experiment can swap heads between datasets and keep the backbone.
