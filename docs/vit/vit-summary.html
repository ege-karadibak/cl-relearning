Does a network that forgot CIFAR-10 relearn it faster?

Yes, with a Vision Transformer too. After it looked forgotten, A relearned CIFAR-10 7.8 points better than a network trained on other photos, and 11.3 points better than one trained on nothing, in every seed. With ResNet-18 the first gap was 7.2.

Three copies, three paths

Learn → overwrite with house numbers → relearn CIFAR-10 from 5,000 photos. Same random start within a seed; only stage 1 differs.

A · test subject

Learned CIFAR-10, then had it overwritten.

C · the fair control

Same training effort on similar photos, different labels. A vs C isolates CIFAR-10-specific knowledge.

B · baseline

No stage 1. Less training overall, so A vs B mixes two effects.

How it was measured

Every score is on the 10,000 CIFAR-10 test photos, which nobody trains on. Settings were chosen on separate validation photos with rules written down first.

Model

ViT backbone (10.7M params: 4×4 patches, 6 blocks, width 384) + one small linear head per task. Stage 3 gives every arm the same fresh head, so only the backbone differs.

Relearning data

Two separate runs per arm: A-seen 5k (photos A trained on) and never-seen 5k. 4,000 steps ≈ 100 passes.

Three ways to read knowledge

  • Old head: the classic forgetting score
  • Probe: fresh linear reader, backbone frozen
  • Relearning: everything trains

Calibrated settings

  • AdamW · stage 1: lr 5e-4, 200 epochs
  • Probe C = 0.001
  • Stage 2: lr 3e-4, 20 epochs (A and B SVHN ≥ 95%, lowest old head)
  • Stage 3: lr 1e-4, 4,000 steps (best mean of A, B, C)

Stage 1: both learned, and photo skills transfer

A reaches 88.3% on CIFAR-10 (ResNet-18: 94.9%): a ViT trained from scratch on 40k small photos is weaker. C never saw CIFAR-10, yet a probe on its backbone already gets 69%. Random weights give 33%.

Is it real? A − C is positive in every seed

Each dot is one seed; the bar is the mean. The final gap (7.8 ± 0.8) is about 10× its spread. The extra gain during relearning (5.5 ± 0.7) is positive in every seed too.

A − C, percentage points, per seed

Head start, or faster? Both

Of A's 7.8-point lead over C, about 2.3 was there before relearning and about 5.5 was gained during it. Lined up from the same 50% point, A still climbs fastest: +22.5 points in the next 500 steps, against +16.5 for C and +10.9 for B.

Probe at start (light) + gain during relearning (solid) = final
Curves lined up where each run first reaches 50%

Specific photos: a small memory effect, in every seed

On photos it had trained on, A relearned ~2.0 points better than on new photos. B and C, which never saw them, show almost no difference (+0.3, +0.2). So A's extra edge, ~1.8 points, is positive in every seed. With ResNet-18 it was ~1 point and changed sign across seeds.

Memory effect = (A-seen − never-seen) for A, minus the same for C or B · per seed

Limits

The main gap is solid; these bound what it means.

A's old head during the 20-epoch stage-2 calibration, three learning rates (validation)

Old head not near chance

A's old head 29% (chance 10%); probe 58.5% (> B's 43.8%). The ViT looks less forgotten than ResNet-18.

Rules adapted to the ViT

Old-head rule changed; 20 SVHN epochs instead of the smallest length; stage-3 budget doubled. All before any relearning result.

Different recipe

AdamW, warmup, RandAugment, other lengths than ResNet-18. Compare gaps between arms, not raw accuracies.

Small scale

3 seeds, one ViT size (10.7M), 32×32 images, 5k relearning photos.
