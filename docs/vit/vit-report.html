Does a forgotten Vision Transformer relearn faster?

The same experiment as with ResNet-18, repeated with a very different network: a small Vision Transformer. It learns CIFAR-10, then "forgets" it by training on house-number digits. We test whether the forgotten knowledge is really gone, or still hidden in the weights and quick to come back.

Runs finished 17 Nov 2026Lab GPU: RTX PRO 6000 BlackwellPyTorch 2.15.0All numbers: mean of seeds 1–3, CIFAR-10 test set unless markedOne-page summary · vs ResNet-18

The answer in one paragraph

Yes, and almost exactly as much as with ResNet-18. After SVHN training, the ViT's old CIFAR-10 classifier dropped from 88.3% to 29.2%, so A looked largely forgotten. But when all three networks relearned CIFAR-10 from the same 5,000 images, the one that had learned CIFAR-10 before (A) ended 7.8 points above a network that had learned a different photo dataset (C), and 11.3 points above one that had learned nothing (B). That held in every seed. About 2 of those 8 points were already visible before relearning started. The other ~5.5 came from A improving faster during relearning. Unlike ResNet-18, the ViT also showed a small but consistent memory of the specific photos it had trained on (~1.8 points, positive in every seed).

01The question

In plain words

The ResNet-18 experiment showed that a network which seems to have forgotten a task relearns it faster than one that never learned it. Here we ask whether that is a quirk of one kind of network. A Vision Transformer reads images in a completely different way, so if the same thing happens, it is more likely a general property of how networks learn.

Neural networks trained on one task and then on another lose accuracy on the first task (catastrophic forgetting). It is normally measured with the network's original output layer, which can stop working simply because the layers below it changed, even if the information is still there.

The question is the same as before: after a network appears to have forgotten a task, does it relearn that task faster and better than an equally trained network that never learned it? If yes, the "forgotten" knowledge was hidden, not erased. This report repeats every stage with a ViT, with the same data, splits, arms, seeds and measurements, and only the network (and the training recipe it needs) changed.

What would count as an answer

  • Hidden: A relearns CIFAR-10 better than C, consistently across seeds, by more than the seed-to-seed noise.
  • Erased: A relearns no better than C.
  • Beyond ResNet-18: is the size of the effect similar? Does the ViT keep a different kind of knowledge (general vs CIFAR-10-specific)?

02Design: three arms, three stages

In plain words

Three copies of the same network take different paths. A learns CIFAR-10, B learns nothing, C learns CIFAR-100. Then all three learn house numbers, which overwrites what they knew. Finally, all three learn CIFAR-10 from a small set of photos, and we watch who learns fastest. The design is identical to the ResNet-18 experiment.

04The ViT and its heads

In plain words

A ResNet slides small filters over the picture. A Vision Transformer instead cuts the picture into small squares ("patches"), turns each square into a list of numbers, and lets every square look at every other square to decide what matters. A special extra slot, the class token, collects a summary of the whole picture: 384 numbers. As before, a small head turns those numbers into an answer, and each task gets its own head. A step-by-step example is in How a ViT sees a picture.

The backbone

torchvision's VisionTransformer, sized to match ResNet-18 (10.7M vs 11.2M parameters): 32×32 input, 4×4 patches (64 patches), hidden width 384, 6 transformer blocks with 6 attention heads each, MLP width 1,536. A learned class token is added to the patches, and its final 384 numbers are the features. The ImageNet classification layer is removed.

ResNet-18ViT (this report)
How it reads the image3×3 filters slid over the image, layer after layer64 patches of 4×4 pixels; every patch can attend to every other one from the first block
Built-in assumptionsnearby pixels belong together; a pattern means the same anywherealmost none: it must learn them from data, so it needs more data or stronger augmentation
Normalization layersBatchNorm: keeps running averages of the data it seesLayerNorm: normalizes each image on its own, keeps no data statistics
Features512 (global average pool)384 (class token)
Parameters (backbone)11,168,83210,691,712

The normalization row looked important for this experiment: BatchNorm's running statistics get overwritten when a network trains on new data (here SVHN), even if the filters change little, and a ViT has no such statistics. We tested whether this explains the difference in old-head forgetting; it does not (section 11).

What a head is, and why a fresh one in stage 3

A head is a linear layer: scores = W·x + b, with W of shape 10×384 for a 10-class head. It has learned what each of the 384 slots means in that backbone. When stage 2 changes the backbone, the slot meanings shift and the old head reads the wrong evidence, so the old head can fail even when the information is still present. In stage 3, every arm gets an identical, freshly seeded head, so the backbone is the only thing that differs.

05How every stage trains

In every stage, the backbone and the active head train together. A new optimizer is built at the start of each stage, so no optimizer state carries over and old heads stay frozen. The recipe differs from ResNet-18's because ViTs trained from scratch need one: AdamW instead of SGD, a warmup in every stage, gradient clipping, and RandAugment.

The same reproducibility safeguards as for ResNet-18 apply: seeding before every new head, 8 data workers throughout, full provenance in every checkpoint and log, crash-safe resume files, and no overwriting of finished results. ViT checkpoints also record their architecture, and loading refuses a checkpoint of the other backbone. The real stage-2 runs replayed the seed-1 calibration run exactly (identical SVHN accuracies at every logged step), a direct check of reproducibility on the GPU.

The linear probe

In plain words

Freeze the network, run 5,000 CIFAR-10 photos through it, and fit the simplest possible classifier on the 384 numbers it produces. If that simple classifier does well, the network must still hold the information in an easy-to-read form. The network itself is never changed.

  1. Put the backbone in evaluation mode with no training.
  2. Extract the 384 class-token features for each of the 5,000 never-seen images (no augmentation).
  3. Standardize each feature, then fit logistic regression (scikit-learn, C = 0.001, up to 2,000 iterations).
  4. Score it on the 10,000 CIFAR-10 test images (validation during calibration), then throw it away.

Relearning metrics

Identical to ResNet-18. Every metric uses a smoothed curve (each point is the mean of itself and the previous two measurements), because single measurements jump by several points.

Is a difference real? Differences between arms are paired by seed (same random start). A difference is convincing when its mean is clearly larger than its spread across seeds, with the same sign in every seed. Paired t-tests are a rough guide only (2 degrees of freedom).

07Calibration: choosing settings without peeking

In plain words

Settings like the learning rates can change the result. To avoid picking whatever makes the hypothesis look good, every setting was chosen by trial runs scored on the validation photos (never the test set), with a rule written down before the trial, then frozen in the config file. The ViT needed more calibration than ResNet-18, and two rules had to be adapted to it; each change is recorded here with the moment it was made.

All calibration used seed 1, except the stage-1 learning rate (seeds 1–3). Rules, results and changes are recorded as comments in configs/vit/*.yaml.

A first attempt was discarded. The first ViT recipe used a stage-1 learning rate of 1×10⁻³. Stage 1 then depended strongly on the seed (A: 76.8% / 82.3% / 75.0% on test, with a long stall that only seed 2 escaped), and in the stage-2 calibration B never learned SVHN at that rate. All those runs were archived (logs/vit/archive_lr1e-3/) and nothing from them is used below.

7.1 · Stage-1 learning rate

Rule (fixed before running): for each rate, train A for the full 200 epochs on seeds 1, 2 and 3, scored on validation. A run's score is its mean validation accuracy over the last 5 epochs. A rate is stable if its three scores lie within 2 points. Choose the stable rate with the highest mean; if neither is stable, try 1×10⁻⁴.

7.3 · Stage-2 learning rate

Starting rule (ResNet-18's): the gentlest rate where, after a 20-epoch trial, A's SVHN ≥ 95% and A's old head ≤ 15%, and B's SVHN ≥ 95%. Stage 2 also got a 1-epoch warmup for every arm, after B failed without one in the discarded first attempt.

Rule change (made after the 1×10⁻³ trial only, before the 3×10⁻⁴ and 1×10⁻⁴ results): at 1×10⁻³, the strongest rate, A's old head fell from 88.8% to about 20% by epoch 3.5 and then stayed flat for 16 epochs. Gentler rates forget less, so no rate could reach 15%. The aim, "A clearly looks forgotten", was kept, without a cut-off this backbone cannot reach: among the rates where A and B both reach SVHN ≥ 95%, take the one where A's old head ends lowest (within 2 points, the gentler one).

7.4 · Stage-2 length

Rule (adapted with the rule change above): the smallest whole number of SVHN epochs at which A's old head is within 2 points of its lowest value (it has stopped dropping); then check that B reaches SVHN ≥ 95% at that length, with a full schedule of that length, and lengthen if not.

  1. At 3×10⁻⁴, A's lowest old head was 31.1%. It first came within 2 points at step 5,000 (epoch 8.7) and stayed between 31% and 34% afterwards → 9 epochs.
  2. B trial at 9 epochs (5,157 steps): 92.2% on SVHN, so the rule says lengthen.
  3. Instead of searching 10, 11, … epochs one by one, we used 20 epochs: the calibration run itself, already measured to pass for both arms (B 95.7%, A 96.2%). This was decided after the 9-epoch trial and before any stage-3 result.
What this choice means. 20 epochs is a known passing length, not the smallest one. A's old head (31–34%) and probe (~58–59%, B ~45%) are flat from epoch 9 to 20, so the longer overwrite changes A little and, if anything, makes an A advantage harder to show. Unlike ResNet-18, where A's forgetting set the length, here B (learning SVHN from random weights) set it.

7.5 · Stage-3 learning rate

Rule (ResNet-18's, including its averaged reading, fixed before any ViT stage-3 run): try 3×10⁻⁵, 1×10⁻⁴, 3×10⁻⁴ and 1×10⁻³ for A, B and C (seed 1, never-seen, validation, 2,000 steps). One rate for all arms: the highest mean validation accuracy over A, B and C, averaged over the last 500 steps. Check 1: report any arm whose own best rate beats the shared one by more than 2 points. Check 2: if any arm still gains more than 1 point in the last 500 steps, double the budget.

Both readings choose 1×10⁻⁴, which is not at the edge of the range.

  • Check 1: A and C are best at 1×10⁻⁴. B is best at 3×10⁻⁴, only 0.56 points higher. No arm is disadvantaged (unlike ResNet-18, where B was 4.6 points below its best).
  • Check 2: gain over the last 500 steps at 1×10⁻⁴ (mean of steps 1,500–2,000 minus mean of 1,000–1,400, the ResNet-18 definition): A +0.2, B +1.5, C +0.6. B still gains more than 1 point, so the budget was doubled to 4,000 steps. With a constant rate, the first 2,000 steps of a 4,000-step run are the same run, so a comparison with ResNet-18 at 2,000 steps stays possible.

Settings that were not calibrated

AdamW's betas and weight decay, gradient clipping, RandAugment (2, 9), the warmup lengths and the batch size follow common recipes for training small ViTs from scratch, and are identical for every arm. Stage 1 is 200 epochs, the same as ResNet-18, so both backbones get the same number of passes.

9.7 · Does the probe predict relearning?

10What it means

In plain words

A Vision Transformer that seemed to have forgotten CIFAR-10 still had a lot of it hidden inside, just like ResNet-18. Given a little practice, it came back clearly better and faster than a network that had practised on similar photos. The size of that advantage was almost the same for both kinds of network.

  1. The main result replicates across architectures. A beats C by 7.8 ± 0.8 points after relearning, in every seed (ResNet-18: 7.2 ± 0.8). At ResNet-18's budget of 2,000 steps the ViT gap is 7.4.
  2. "Forgotten" by the old head is not forgotten. A's old head scored 29%, a fresh linear reader found 58.5%, and relearning reached 80.8%.
  3. Relearning reveals much more than the probe. A − C grows from 2.3 (probe) to 7.8 (relearning). Most of A's surviving CIFAR-10 knowledge is not linearly readable after the overwrite, but training brings it back.
  4. A learns faster, not only from a head start: +5.5 points of extra gain over C, and the fastest climb from a common 50% level.
  5. Different kinds of leftover knowledge. The ViT keeps more general photo knowledge through SVHN (probe C − B 12.4 vs ResNet-18's 5.4), but it helps less in relearning (C − B shrinks to 3.5; ResNet-18's grows to 9.6). The CIFAR-10-specific part (A − C) is what lasts in both.
  6. A small memory of specific photos (~1.8 points, every seed), which ResNet-18 did not show clearly.

Scope of the claim: after 20 SVHN epochs at lr 3×10⁻⁴ (old head 88% → 29%), a 10.7M-parameter ViT that learned CIFAR-10 relearns it from 5,000 images 7.8 points better than an equally trained ViT that learned CIFAR-100 instead.

Why the old heads differ: not BatchNorm. ResNet-18's old head reached 19% after only 4 SVHN epochs; the ViT's stays near 29% even after 20. One idea was that ResNet-18's BatchNorm layers, which keep running averages of the data they see, simply had their averages replaced by SVHN's, while the ViT's LayerNorm keeps none. We tested it (src/bn_check.py, 18 Nov): recomputing only ResNet-18's BatchNorm statistics from CIFAR-10 images, with no weight changes, does not bring the old head back.

The old head even drops slightly, in every seed. The recompute has a small cost of its own (on a never-overwritten stage-1 model it costs 1.7 points, probably because the saved statistics came from augmented training images), but compared like for like, CIFAR statistics beat SVHN statistics by only 1.5 points. ResNet-18's forgetting is in the weights, not in its normalization statistics. A better candidate is how strongly each network was overwritten: in the ViT's calibration its old head ended at 37%, 31% and 20% for stage-2 rates of 1×10⁻⁴, 3×10⁻⁴ and 1×10⁻³; at the strongest rate it matches ResNet-18 (19%). The ViT ran at 3×10⁻⁴ because B needed it to learn SVHN. This is a hypothesis from seed-1 calibration runs, not yet tested.

13Open questions and next experiments

  1. Matched overwrite strength: the BatchNorm explanation was tested and ruled out (section 11). Next, compare the two networks at the same amount of old-head forgetting (for example A's ViT stage 2 at 1×10⁻³), and check whether the other differences (general knowledge, memory of photos) remain.
  2. Where is the knowledge kept? Probe every transformer block (and every ResNet stage) at the stage-2 checkpoints, for A, B and C.
  3. How much overwriting erases it? Sweep the stage-2 length and plot the A − C relearning gap.
  4. Does the dataset matter? Change the overwrite dataset, from close to far from CIFAR-10, and measure how similar each one is (gradient and representation overlap).
  5. Direct memory test of the A-seen photos right after stage 2.

14Glossary

Backbone
The large shared part of the network that turns an image into features (384 for this ViT).
Head
A small linear layer on top of the backbone that turns features into class scores. One per task.
Vision Transformer (ViT)
A network that cuts an image into patches and lets every patch attend to every other patch, instead of sliding filters over it.
Patch, token
A 4×4-pixel square of the image, turned into a list of 384 numbers. The network processes 64 patch tokens plus one class token.
Class token
An extra learned token that gathers information from all patches; its final 384 numbers are the image's features.
Attention
Each token computes how relevant every other token is, and takes a weighted mix of their information.
Transformer block
Attention followed by a small two-layer network, each with LayerNorm and a skip connection. This ViT has 6.
LayerNorm vs BatchNorm
Both rescale numbers inside the network. BatchNorm uses running averages over the training data; LayerNorm uses only the current image.
AdamW
An optimizer that adapts the step size for every weight, with weight decay applied separately.
Warmup, cosine schedule
Warmup raises the learning rate from near zero over the first steps; cosine lowers it smoothly to zero.
Gradient clipping
Limits the size of one update, to avoid sudden jumps.
RandAugment
Applies random image operations (rotate, shear, contrast, …) to every training image.
Arm, seed
An arm is one version of the experiment (A, B or C). A seed is the starting number for all randomness.
Linear probe, C
A logistic-regression classifier fitted on frozen features. C is its inverse regularization strength.
Calibration
Choosing settings with trial runs on validation data, using a rule fixed in advance.
AUC
Here: average accuracy over the whole relearning curve.
