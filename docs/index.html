cl-relearning · documentation

Does a network that forgot something relearn it faster?

A network learns CIFAR-10, has it overwritten by house-number digits (SVHN), then relearns CIFAR-10 from 5,000 images, compared with networks that first learned CIFAR-100 or nothing. Run with two backbones: ResNet-18 and a Vision Transformer (ViT), 3 seeds each.
