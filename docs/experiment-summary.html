Does a network that forgot CIFAR-10 relearn it faster?

Yes. After it looked forgotten, A relearned CIFAR-10 7 points better than a network trained on other photos, and 17 points better than one trained on nothing, in every seed.

Three copies, three paths

Learn → overwrite with house numbers → relearn CIFAR-10 from 5,000 photos. Same random start within a seed; only stage 1 differs.

A · test subject

Learned CIFAR-10, then had it overwritten.

C · the fair control

Same training effort on similar photos, different labels. A vs C isolates CIFAR-10-specific knowledge.

B · baseline

No stage 1. Less training overall, so A vs B mixes two effects.

How it was measured

Every score is on the 10,000 CIFAR-10 test photos, which nobody trains on. Settings were chosen on separate validation photos with rules written down first.

Model

ResNet-18 backbone (11.2M params) + one small linear head per task. Stage 3 gives every arm the same fresh head, so only the backbone differs.

Relearning data

Two separate runs per arm: A-seen 5k (photos A trained on) and never-seen 5k. 2,000 steps ≈ 50 passes.

Three ways to read knowledge

  • Old head: the classic forgetting score
  • Probe: fresh linear reader, backbone frozen
  • Relearning: everything trains

Calibrated settings

  • Probe C = 0.1
  • Stage 2: lr 0.03, 4 epochs (A's old head ≤ 15%, all SVHN ≥ 95%)
  • Stage 3: lr 0.003 (best mean of A, B, C)

Is it real? A − C is positive in every seed

Each dot is one seed; the bar is the mean. The final gap (7.2 ± 0.8) is about 8× its spread. The extra gain during relearning (4.2 ± 1.4) is positive but noisier.

A − C, percentage points, per seed

Head start, or faster? Both

Of A's 7.2-point lead over C, about 3.0 was there before relearning and about 4.2 was gained during it. Lined up from the same 50% point, A still climbs fastest.

Probe at start (light) + gain during relearning (solid) = final

Specific photos: no clear evidence of memory

A did ~2 points better relearning on its old photos, but C (which never saw them) did ~1 point better too. A's extra edge, ~1 point, changes sign across seeds.

Memory effect = (A-seen − never-seen) for A, minus the same for C or B · per seed
